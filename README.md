# Pixel · Design

[Baixe o ZIP](https://github.com/aggak/pixel-dfe/archive/refs/heads/teste-design.zip), extraia e abra o terminal na pasta extraída.

```sh
npm ci
npm run dev
```

Abra [localhost:5173/design/index.html](http://localhost:5173/design/index.html).

No rodapé, **Testar design** permite trocar as cores e os cenários.
