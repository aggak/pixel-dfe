# Pixel · Design

Requer Node.js 24 ou superior.

1. Abra o terminal na pasta do projeto e execute:

   ```sh
   git fetch origin
   git switch teste-design
   npm ci
   npm run dev
   ```

2. Sem fechar o terminal, clique em **[Abrir o design](http://localhost:5173/design/index.html)**.
   Se o terminal mostrar outra porta, troque `5173` pelo número indicado.

3. No rodapé da página, abra **Testar design** para comparar cores e situações.

Não precisa iniciar a API: os dados são de exemplo e reiniciam ao recarregar a página.
