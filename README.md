# Pixel · Design

1. Instale o [Node.js 24 ou superior](https://nodejs.org/pt-br/download).
2. [Baixe o design em ZIP](https://github.com/aggak/pixel-dfe/archive/refs/heads/teste-design.zip) e extraia o arquivo.
3. Abra o terminal na pasta extraída `pixel-dfe-teste-design` e execute:

   ```sh
   npm ci
   npm run dev
   ```

4. Sem fechar o terminal, clique em **[Abrir o design](http://localhost:5173/design/index.html)**.
   Se o terminal mostrar outra porta, troque `5173` pelo número indicado.

No rodapé, abra **Testar design** para comparar cores e situações.

Não precisa iniciar a API: os dados são de exemplo e reiniciam ao recarregar a página.
